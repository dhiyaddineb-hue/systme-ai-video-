# القفل الإبداعي الأصلي — «سيف الظل»

هذا هو المرجع الأساسي للإنتاج القادم، وليس «النجم الأسود».

## المرجع

- الحزمة: `package_manga_recap_pilot/`
- العنوان: **سيف الظل**
- النوع: ملخص مانهوا مصري سريع
- الصوت المرجعي: `ar-EG-ShakirNeural` / البديل العربي المقاس فعلياً
- المرجع البصري والمونتاجي: `v5-fixed` داخل الحزمة

## القواعد غير القابلة للتغيير

1. افتتاحية مباشرة داخل الحدث، بدون مقدمة طويلة.
2. بطل واحد مقفول بصرياً: كريم.
3. ست لوحات أصلية، كل لوحة تخدم مرحلة واضحة من القصة.
4. الحركة تخدم المعنى: zoom/pan/flash، وليست قصّات عشوائية.
5. whoosh عند الانتقال، impact عند الضربة، وducker للصوت.
6. كاريوكي ذهبي متزامن مع الكلام.
7. تصاعد واضح: إذلال → اكتشاف → قوة → نزال.
8. نهاية cliffhanger قصيرة.
9. لا نستخدم ستايل «النجم الأسود» أو نغيّر اللهجة/الشخصيات إلا بقرار صريح.

«النجم الأسود» يبقى أرشيفاً وتجربة منفصلة، ولا يُستخدم كمرجع للحلقات القادمة.
