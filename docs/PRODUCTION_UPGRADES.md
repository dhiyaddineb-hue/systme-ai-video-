# تطوير النظام الإنتاجي

## الإصدار الحالي

أضيفت بوابة تدقيق موحّدة للحزم:

```bash
python3 -m vtsys audit package_black_star_ep2
python3 -m vtsys audit package_black_star_ep2 --rendered
```

### ما الذي تمنعه البوابة؟

- ملفات القصة أو الهوية المفقودة.
- جمل بلا صوت أو شيت بصري.
- تكرار مالك بصري لجملتين مختلفتين.
- فيديو نهائي أو storyboard مفقود بعد الرندر.
- storyboard بلا لقطات أو بلا ختم PASS.

## خارطة التطوير التالية

1. **Manifest إنتاجي**: بصمة SHA-256 لكل مدخل ومخرج، مع نسخة محرك البناء.
2. **اختبار صوتي**: قياس الصمت، clipping، وطول كل VO قبل الرندر.
3. **اختبار بصري آلي**: كشف الإطارات السوداء، دقة 16:9، وتنوع MD5 بين اللقطات.
4. **استئناف آمن**: إعادة بناء الأجزاء المفقودة فقط بعد تدوير البيئة.
5. **تقارير نشر**: تقرير واحد يضم المدة، الحجم، الترميز، التغطية، ونتائج البوابات.
6. **دعم أصوات متعددة**: قفل voice_id واللغة واللهجة في canon لكل مشروع.

كل ترقية يجب أن تبقى قابلة للتشغيل محلياً بلا شبكة، ولا تسمح بتجاوز بوابات التدقيق في وضع النشر.

## إصلاح المونتاج — 2026-09-19

المشكلة المكتشفة لم تكن في الـ audit فقط:

- بطاقة العنوان كانت تُركّب فوق أول خمس ثوانٍ من اللقطات، فتشوّش بداية المشهد وتكسر الإيقاع.
- المصدر البصري كان contact sheet واحداً؛ القصّات صحيحة هندسياً لكنها لا تضمن استمرارية الوجه والملابس بين اللوحات.

الإصلاح الأول المنفذ:

- وضع الفيلم صار يرندر **المشهد والكابشن فقط** بلا overlay للعنوان/النهاية فوق المادة السردية.
- العنوان والنهاية يبقيان في صفحة المعاينة، ولا يغطّيان اللقطة أثناء الكلام.
- أُعيد رندر الحلقة الثانية وتحققنا بصرياً من بداية نظيفة وحركة crop طبيعية.

الإصلاح التالي الإلزامي للصور:

- توليد كل لوحة رئيسية كصورة مستقلة مع مرجع الشخصية، ثم بناء الشيت منها؛ لا استخدام contact sheet مولّد كأنه 6 لقطات نهائية.
- فحص continuity للوجه، الشعر، الملابس، الإضاءة، وموقع العنصر قبل دخول المونتاج.
