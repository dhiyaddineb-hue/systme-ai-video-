# النجم الأسود

قصة مانغا منظمة في مجلد خاص (§4.11) — عالم أكاديمية النجوم الساقطة.

- البطل: آدم، أضعف طالب، يستدعي النجم المحرّم.
- الحلقة الأولى: hook → سؤال معلق → إذلال → قوة خفية → صدمة → تهديد → cliffhanger.

## التشغيل
```bash
python3 build.py            # النسخة v1 (نبضات)
python3 build.py --film     # وضع الفيلم §4.12 (كل معنى لقطتها)
```
