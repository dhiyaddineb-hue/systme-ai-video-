# 🧠 الذاكرة السجلية — بروتوكول الحفظ الدائم

> **القاعدة:** كل شيء يُحفظ في المستودع. لا معرفة في الذاكرة المؤقتة فقط.
> هذا المجلد هو **ذاكرة النظام عبر الجلسات** — يُقرأ أول كل جلسة، ويُحدّث آخرها.

## البروتوكول (إلزامي)

| متى | ماذا |
|---|---|
| 🟢 **بداية كل جلسة** | اقرأ `memory/STATE.md` كاملاً قبل أي عمل |
| 🟡 **أثناء الجلسة** | سجّل الأحداث المهمة: `python3 memory/log.py "الحدث" --tag قرار` |
| 🔴 **نهاية كل جلسة** | حدّث `STATE.md` (ما تم / القادم) + سجل الجلسة اليومي + `LOG.md` |

## الملفات

```
memory/
  README.md              هذا البروتوكول
  STATE.md               الحالة الحالية: آخر جلسة، ما تم، القادم، تنبيهات (يُقرأ أولاً)
  LOG.md                 سجل تراكمي مختصر لكل الأحداث (append-only، الأحدث في الأسفل)
  decisions.md           سجل القرارات المعمارية المهمة مع أسبابها
  log.py                 مساعد التسجيل: إلحاق حدث مؤرخ في LOG + ملف اليوم
  sessions/
    YYYY-MM-DD.md        سجل تفصيلي لكل جلسة عمل
    assets/              أدلة صغيرة (لقطات، تقارير JSON… — حد أقصى ~1MB للملف)
```

## ماذا يُحفظ وأين؟

| النوع | المكان | السبب |
|---|---|---|
| المعرفة والدروس | `SYSTEM_KNOWLEDGE.md` (§7+) | مصدر الحقيقة |
| الأحداث والقرارات والحالة | `memory/` | ذاكرة سجلية |
| الأصول النصية الصغيرة (story/narration/script/json/ass) | `examples/` + `runs/**` (مستثناة من التجاهل) | إعادة بناء كاملة منها |
| الباكجات النهائية ≤30MB | `package_*/` | التسليم |
| الطابور | `queue.json` (متتبَّع في git) | حالة النشر تنجو بين الجلسات |
| الوسائط الثقيلة (mp4/mp3/m4a خام) | `build/` (خارج git) | قابلة لإعادة البناء من النصوص — حماية سقف Snapshot |
